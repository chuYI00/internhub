# 实习岗位聚合器 InternHub

一个本地运行、个人学习使用的实习岗位聚合网页工具：定时抓取公开实习信息 → 存入本地 SQLite → 网页按地区/关键词筛选 → 点击原始官方链接投递。

> ⚠️ **合规与免责声明（请务必阅读）**
> - 本工具仅用于**个人求职辅助 / 学习交流**，聚合的是网络公开信息，请勿商用或二次分发他人岗位信息。
> - 默认**遵守目标站点 robots.txt**、低频抓取（每页间隔 1.5s+），不绕过验证码、不暴力爬取。若站点条款或 robots 不允许，请改用官方 API/官网渠道。
> - 本工具**不担保岗位真实性**，不参与招聘；页面保留**原始官方投递链接**，投递前请自行到官方渠道核实，谨防“付费内推/培训费/押金”类虚假岗位。
> - 岗位数据有延迟，页面会显示“最近更新时间”，过期岗位由抓取方页面状态为准。

## 快速开始

```bash
# 1) 进入项目
cd intern_tool

# 2) 创建虚拟环境并安装依赖
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux
pip install -r requirements.txt

# 3)（可选但推荐）安装 Node.js，用于解析实习僧页面内嵌结构化数据（薪资字段更准确）。
#    不安装也会自动降级为“备用 DOM 解析”，薪资显示为面议/原始文本。

# 4) 先手动抓一次（北京 2 页）试试
python run_crawl.py --cities 北京 --pages 2

# 5) 启动网页
streamlit run app.py
# 浏览器打开 http://localhost:8501
```

## 自动定时更新

本地保持运行（每 6 小时抓一次，可改 `--hours`）：

```bash
python scheduler.py --hours 6 --cities 北京,上海,深圳
```

想不依赖个人电脑 24h 在线，可用 GitHub Actions / 云函数按 cron 定时调用 `run_crawl.py`，并把 `data/jobs.db` 同步到部署环境（见 README 部署章节）。

## 功能

- 数据源：实习僧（当前），架构支持后续扩展牛客/高校就业网/企业官网等
- 字段：岗位名称、公司、城市、薪资、学历要求、标签、来源、**原始投递链接**
- 筛选：城市 / 关键词；未来可加 薪资区间、岗位类型、是否远程
- 真实性过滤：规则层拦截“付费内推/培训费/押金”等风险词并打标；页面免责声明
- 去重：同一岗位重复抓取只保留一条（按 来源+岗位id）；跨平台去重键预留
- 收藏：网页内可勾选收藏
- 时间：每条岗位显示**收录时间**；勾选“详情页截止时间”可补抓 **截止日期**，支持“只看未截止”“近3/7/30天”筛选
- 其他来源：可 **CSV 导入**（`run_import.py`，参考 `示例_导入模板.csv`），适合把官网/群文件里整理的清单导进来
- 合规：robots 检查、限速、低频；原始链接原样保存

> 说明：招聘平台公开列表大多不提供“发布日期”；截止日期需进岗位详情页抓取（较慢，逐条抓）。牛客/BOSS/智联等大平台为强反爬+需登录，暂不接入，避免合规与封禁风险。

## 目录结构

```
intern_tool/
├─ app.py                # Streamlit 网页
├─ run_crawl.py          # 命令行单次抓取（--enrich N 补抓截止时间）
├─ run_import.py         # CSV 导入其他来源岗位
├─ scheduler.py          # 定时抓取（可常驻/配 cron）
├─ 示例_导入模板.csv
├─ requirements.txt
├─ ihub/
│  ├─ config.py          # 配置：城市、省份、限速、robots 开关等
│  ├─ db.py              # SQLite：建表/迁移/去重写入/查询/收藏/截止
│  ├─ filters.py         # 虚假岗位规则过滤
│  └─ crawlers/
│     ├─ base.py         # 爬虫基类（robots 检查、限速）
│     └─ shixiseng.py    # 实习僧：Node 解析 __NUXT__ 或 DOM 备用 + 详情截止
└─ data/jobs.db          # 运行时生成
```
