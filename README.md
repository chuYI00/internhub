# InternHub · 秋招工作台（昆明/大理 + 云南烟草备考）

![Python](https://img.shields.io/badge/Python-3.10%2B-blue) ![Streamlit](https://img.shields.io/badge/UI-Streamlit-red) ![License](https://img.shields.io/badge/License-MIT-green)

一个**本地运行、个人求职辅助**的 2027 届秋招工作台。主线只有一条：

**看岗位 → 官方投递 → 网申填表 → 定制简历 → 备考目标单位**

网页收敛成 **4 个页签**，对应这条主线的四步（烟草公告不占页签，出现在「🎯 岗位」顶部横幅）。
默认视图 = **秋招 × 云南（昆明 / 大理）**，技术岗优先。

> ⚠️ **合规与免责声明（请务必阅读）**
> - 仅用于**个人求职 / 学习交流**，勿商用或二次分发他人岗位信息；
> - 默认**遵守目标站点 robots.txt**、低频抓取（每页间隔 1.5s+），不绕过验证码、不暴力爬取；
> - **不担保岗位真实性**、不参与招聘、**不自动代投**（脚本代投违反平台规则且易封号）；投递前请点击原始链接到官方渠道核实，谨防“付费内推 / 培训费 / 押金”类骗局；
> - 公开列表大多不提供“发布日期”，页面以“收录时间 + 截止时间（详情页）”为准。

## ✨ 功能（按 4 个页签）

### 🎯 页签 1 · 岗位（看岗位 + 拿官方投递入口）
- **秋招岗位流**：默认秋招 × 昆明/大理；「秋招 / 实习」是一级开关，实习数据保留、切过去就能看
- **🍃 烟草公告横幅**：顶部显示最新公告的**报名窗口 / 剩余天数 / 是否限报 1 岗**（读本地已扫结果，不联网）
- **🚀 官方投递直达**：每条岗位给「企业官方投递页」（应届生求职网的跳转壳会自动解码成企业网申系统地址）；岗位表拆成「✅ 官方报名（企业域名）」与「来源页（非官方）」两列，**不让平台页冒充官方**
- **🌏 云南秋招渠道地图**：27 家单位 / 8 类（烟草 / 电网 / 机场 / 航产投 / 建投 / 运营商 / 银行 / 民航…），每家给官方公告栏目 + 对口岗位 + 招聘节奏 + 避坑；拿不到官方直达的会**明说**，不硬凑
- **🌐 全网平台入口矩阵**：22 个正规平台（国聘 / 24365 / BOSS / 智联 / 牛客 / 应届生 / 云南人才网 / 昆明·大理人社 / 各校就业网…），每平台给「入口 + 是否需登录 + 能否自动抓 + 云南筛选技巧 + 今日 6 步动作」
- **🍃 烟草岗位推荐**：9 类岗位按「合适 / 轻松 / 钱多」三维 1~5★ 打分，权重可拖滑条 —— 默认权重下技术岗（数字信息 / 机电自动化 / 质量检验）全面优于生产操作类
- **📥 导入我的岗位表**（页顶一级区块，四条通道收敛成一处，详见 `导入教程.md`）：
  ① 上传 CSV / Excel（xlsx 内置读取，不用装 openpyxl；UTF-8/GBK 自动试）
  ② 复制粘贴（飞书/Excel 框选 Ctrl+C，没表头也能按内容猜列，第一行不丢）
  ③ **飞书抓包解码**（被禁复制/导出/打印时用）：F12 Network 拿 `H4sI` 开头的 base64 →
  `解码飞书表格.py` 解成 CSV → 一键读进向导
  ④ 截图 OCR（兜底，留接口）
  统一流程：解析 → 预览前 8 行 → **字段映射确认**（乱列名"单位/雇主/网址"都能映射，没用到的列并进备注）→ 勾选确认 → 入库去重

### 📮 页签 2 · 投递与网申（投了什么、别重复投）
- **投递台账**：新增 / 改状态（待投 / 已投 / 笔试 / 面试 / 未通过）/ 去重提醒 / 导出
- **🚫 烟草「1 单位 1 岗」拦截**：烟草同批次登记第 2 个岗位直接**红框拦住、不静默入库**；前一条已「未通过」不占名额，允许改报
- **📥 从网申助手粘贴导入**：解析 → 预览（新增 / 只改状态 / 冲突）→ 勾选确认 → 导入
- **🔍 链接体检**：全项目链接分 A/P/B/C/D 五级，A 级（企业自己的域名 + 页面内容对得上）才能当「官方投递直达」主按钮
- **渠道清单下载**：投递入口清单（txt / CSV）、云南渠道地图、全网平台矩阵

### 📄 页签 3 · 简历定制（按岗位出定向简历）
- 粘一段 JD → 自动识别岗位方向（9 套）→ 给出**匹配度 + 命中/未体现的关键词** → 生成该方向的**单页定向简历（docx / pdf）** + 20 项**网申填写文案**（一键复制）
- 岗位页选一条岗位点「📄 定制这份简历 →」就能把公司 / 岗位带过来

### 📚 页签 4 · 备考方案
- **🎓 备考方案生成器**：选目标单位（6 个内置 + 自定义）、目标岗位、考试日期、每天可学时长 → 出一份像教培老师给的方案：**考情分析（科目/权重/题型）→ 重点排序（该抓什么、可以放弃什么）→ 按考试日倒推的分阶段计划 + 每日时间表 → 必背清单 → 真题与资料来源 → 面试准备 → 避坑**
- 内置**云南烟草冲刺模板**：行测提速策略、烟草行业常识必背清单（国家局架构 / 云南烟叶地位 / 专卖法要点 / 电子烟 / 烟叶税）、专业知识按电气·机械·计算机分三套、每日课表随「每天几小时」变形，只剩几天自动切冲刺模式
- 可导出 md / docx；命令行 `生成备考方案.bat` 或 `run_studyplan.py` 也能出方案
- **✅ 打卡清单**：按目标分别记录进度，本地保存

### 🤖 两个浏览器脚本（跨页签共用）
- **网申助手 v4**（油猴 `网申助手.user.js`）：按岗位方向一键填 40 类字段，含下拉 / 单选 / 日期 / 富文本 / iframe；**兼容企业自研 ATS**（北森 / Moka / 飞书：`.ant-select`/`.el-select` 自绘下拉自动点开选、`[role=radio]` 卡片单选点最内层），每字段「📋」复制兜底；面板里能**直接登记本次投递**并复制成 TSV 回填台账
- **采集助手 / 采集书签**：在需登录的平台上采集岗位，导出 CSV 回工具
- 装不上扩展也有 **`网申书签.txt`**（书签栏一点即填）

### 🔍 数据质量
- **链接体检**（`run_linkcheck.py`）：逐条验证可达性 + 落点域名 + 关键词对得上，输出 `链接体检报告.md` 与 `data/link_health.json`；**伪直达（点开只是搜索引擎结果页）已全部移除**
- **采集链路**：声明式多源（`sources.json`，27 个源）+ 跳转壳解码 + 单源超时重试；实测前端渲染的平台（BOSS / 智联 / 牛客 / 国聘…）不做硬爬，改用平台入口 + 筛选技巧
- **真实性过滤**：规则层自动标记「付费内推 / 培训费 / 押金」类风险岗位
- **合规**：robots 检查、限速、低频、保留原始链接；页面常驻免责声明；本地运行，资料不上传

### 🧪 自测
`tests/run_all.py` 一键跑 **14 组**全绿（采集 / 网申 / ATS / 书签 / 烟草监控 / 链接体检 / 台账 / 备考方案 / CSV 导入 / 网页冒烟 / 简历定制 / 页签对齐静态检查…）。

## 🚀 快速开始（本地）

```bash
# 1) 进入项目
cd intern_tool

# 2) 虚拟环境 + 依赖
python -m venv venv
venv\Scripts\activate            # Windows
# source venv/bin/activate       # macOS / Linux
pip install -r requirements.txt

# 3)（推荐）安装 Node.js —— 实习僧结构化解析更准；未安装会自动降级 DOM 解析

# 4) 先抓一批数据（城市可换，如 北京 或 潍坊）
python run_crawl.py --cities 潍坊,济南,青岛 --pages 2

# 5) 启动网页 → http://localhost:8501
streamlit run app.py
```

Windows 用户也可直接双击仓库内的 `启动网页.bat` / `抓取数据.bat`。

### 常用命令

```bash
# 抓取 + 补抓前 20 条的详情页截止时间（较慢）
python run_crawl.py --cities 北京 --pages 2 --enrich 20

# 定时每 6 小时自动更新（常驻）
python scheduler.py --hours 6 --cities 北京,潍坊

# 导入其他来源的岗位清单（CSV，UTF-8）
python run_import.py 你的岗位表.csv
```

## 🧱 技术栈

| 层 | 选型 |
| --- | --- |
| 前端/UI | Streamlit（4 页签，同一 `with tabN:` 可分块追加，避免重缩进千行） |
| 数据源 | 实习僧 / 应届生求职网 / 政府与高校公告（声明式 `sources.json`，27 个源并发） |
| 存储 | SQLite（文件型，免部署） |
| 文档生成 | python-docx + reportlab（单页定向简历 docx / pdf；备考方案 md / docx） |
| 浏览器自动化 | Tampermonkey 用户脚本 **v4**（兼容北森/Moka/飞书等 antd·element 自绘控件；本人点击触发，不代登录/不代提交） |
| 链接质量 | 自研体检引擎 `ihub/linkcheck.py`（可达性 + 落点域名 + 页面指纹 → A/P/B/C/D 分级） |
| 备考方案 | `ihub/studyplan.py` 声明式考情档案 + 按剩余天数倒推分阶段 + 课表自适应时长 |
| 合规 | 实名「1 单位 1 岗」拦截（`ihub/ledger.py`）在入库前拦，不静默写入 |
| 任务调度 | 自带 `scheduler.py`；烟草监控已配自动化每 12 小时扫一次并推送 |

```
用户 ─▶ Streamlit (app.py)
          │
          ▼
   ihub/db.py ◀── run_crawl.py / scheduler.py ◀── ihub/crawlers/*（限速+robots）
          │
          ▼
     data/jobs.db  ── 投递工作台 ──▶ 定制投递理由 / 简历 docx / CSV 清单
```

## ☁️ 定时更新不靠电脑常开

用 GitHub Actions 示例：每 6 小时调用一次抓取（需自行解决站点可达性与合规判断，仅作模板思路）：

```yaml
name: crawl
on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch:
jobs:
  crawl:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.11" }
      - run: pip install -r requirements.txt
      - run: python run_crawl.py --cities 北京 --pages 1
      - uses: actions/upload-artifact@v4
        with: { name: jobs-db, path: data/jobs.db }
```
