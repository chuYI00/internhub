# 一、资料分析（最该抢分，每天 30 分钟）

## 1. 必背公式（只背这些）
| 考点 | 公式 |
| --- | --- |
| 基期量 | 基期 = 现期 ÷ (1 + 增长率) |
| 增长量 | 增长量 = 现期 − 基期 = **现期 × 增长率 ÷ (1 + 增长率)** |
| 增长率 | 增长率 = 增长量 ÷ 基期 = 现期 ÷ 基期 − 1 |
| 比重 | 比重 = 部分 ÷ 整体 |
| 比重升降 | **部分增速 > 整体增速 → 比重上升**（反之下降） |
| 平均数 | 平均数 = 总量 ÷ 份数 |
| 平均数增长率 | (1 + 总量增速) ÷ (1 + 份数增速) − 1 |
| 倍数 | A 是 B 的几倍 = A ÷ B；A 比 B 多几倍 = A ÷ B − 1 |
| 年均增长率 | (末期 ÷ 基期)^(1/n) − 1 ≈ (末期÷基期 − 1) ÷ n（估算用） |
| 混合增长率 | 总体增速**介于两部分之间**，且更靠近基数大的那部分 |

## 2. 速算技巧（只练 3 个）
1. **截位直除**：分母截前 3–4 位（看选项差距决定），直接除，够选答案即可
2. **特征数字法**（分数↔百分数，必背表）：
   1/2=50%　1/3≈33.3%　1/4=25%　1/5=20%　1/6≈16.7%　1/7≈14.3%　1/8=12.5%　
   1/9≈11.1%　1/11≈9.1%　1/12≈8.3%　1/13≈7.7%　1/14≈7.1%　1/15≈6.7%　1/16=6.25%
3. **同位比较法**：比较两个分数大小时，先看量级，再比较"分子÷分母"的变化方向，不必精算

## 3. 做题流程（固定动作）
看问题（问增长量/比重/平均数）→ 定位材料数据 → 列式 → **截位直除** → 选最接近项
> 目标：**每题 ≤ 60 秒，正确率 ≥ 75%**。每天 2 篇材料 + 10 道题。

# 二、判断推理（重点刷图形与逻辑，每天 25 分钟）

## 1. 图形推理（只背高频 5 类，偏难怪直接放弃）
1. **对称性**：轴对称 / 中心对称 / 对称轴数量与方向
2. **数量关系**：面的数量、线条数、交点（含笔画数：奇点数为 0 或 2 可一笔画）
3. **位置规律**：平移（方向+步数）、旋转（顺/逆时针+角度）、翻转
4. **样式规律**：遍历（每行每列元素齐全）、叠加（去同存异/去异存同）
5. **立体图形**：空间重构（相对面不相邻、相邻面方向一致）、三视图
> 练习建议：集中刷 100–150 道建立手感，**图推不恋战，40 秒无思路先跳过**。

## 2. 定义判断（送分题）
抓四要素：**主体 + 行为 + 对象 + 条件**；逐项比对，注意问"**不属于**"。

## 3. 类比推理
先定内部关系：并列 / 包含 / 对应（因果、功能、属性、材料）/ 语义（近义、反义）
二级辨析：**词性、感情色彩、范围大小**。

## 4. 逻辑判断（背公式就能拿分）
- **翻译推理**：
  - "如果 A，则 B" → **A → B**（肯前必肯后，否后必否前）
  - "只有 A，才 B" → **B → A**
  - "除非 A，否则 B" → **非 A → B**
- **矛盾关系**（必有一真一假）：A 与 非A；所有是 与 有些非；所有非 与 有些是
- **加强/削弱**：搭桥（补前提）／拆桥（断联系）＞举例＞数据；**削弱力度：直接否定结论最强**
- **分析推理**：优先**排除法**；信息最多的条件先入手；必要时假设法

# 三、言语理解（保语感，每天 15 分钟）

## 1. 片段阅读（拿分主力）
**找中心句**：首尾句、**转折之后**（但是/然而）、**递进之后**（更/甚至）、**结论词之后**（因此/可见/总之/综上所述）。
- 主旨概括 → 选"同义替换"，**不选原文照抄**、不选片面
- 意图判断 → 注意"言外之意"（尤其是问题+危害的段落，多半要选对策）
- 细节理解 → 一一对应，警惕"偷换概念、绝对化表述（都/一定/全部）"
- 标题填入 → 概括性 + 吸引性

## 2. 逻辑填空
两步：**先看语境**（并列/转折/递进/解释说明）→ **再辨词语**（词义侧重、搭配对象、感情色彩）
高频成语（必背）：相辅相成、层出不穷、潜移默化、不谋而合、推陈出新、独树一帜、不可或缺、至关重要、因地制宜、循序渐进。

## 3. 语句排序
技巧顺序：看代词指代 → 关联词搭配 → 时间/逻辑顺序 → 首尾句特征（首句一般不出现指代词/关联词）。

# 四、公基背诵版（云南烟草必考，背了就有分）

## 1. 云南省情（高频，必背）
- 面积 **39.4 万平方公里**，常住人口约 **4700 万**，下辖 **16 个州市**，省会**昆明**
- 与**缅甸、老挝、越南**接壤，陆地边境线约 **4000 多公里**，有 **25 个边境县（市）**
- **三个定位**：民族团结进步示范区、生态文明建设排头兵、面向南亚东南亚辐射中心
- 发展重点提法：**资源经济、园区经济、口岸经济**；"3815"战略发展目标（以最新官方表述为准）
- 支柱/优势产业：**烟草、旅游、电力（绿色能源）、有色金属、生物资源**；中老铁路是标志性开放通道
- 云南是**全国最大烤烟产区**，"两烟"（烤烟、卷烟）产量长期居全国首位

## 2. 烟草行业常识（送分，必背）
- 管理体制：**统一领导、垂直管理、专卖专营**；国家烟草专卖局与中国烟草总公司**一套机构、两块牌子**
- **《烟草专卖法》1992 年 1 月 1 日施行**（1991 年通过）
- **许可证制度**：生产、批发、零售、运输等实行许可证管理；运输需**准运证**
- 烟草专卖品范围：卷烟、雪茄烟、烟丝、复烤烟叶、烟叶、卷烟纸、滤嘴棒、烟用丝束、烟草专用机械
- 包装必须标注**焦油量、烟碱量**及"**吸烟有害健康**"
- **禁止**在广播电台、电视台播放烟草制品广告；禁止向**未成年人**售烟（未成年人保护法）
- **电子烟**已纳入烟草专卖监管（《电子烟管理办法》）
- 云南主要工业企业：**云南中烟工业有限责任公司**（下辖红塔集团、红云红河集团等），主要品牌：**红塔山、玉溪、云烟、红河、红梅**

## 3. 公文基础（高频）
- **15 种法定公文**：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要
- 行文规则：**请示一事一文**；不得越级行文；**报告中不得夹带请示事项**；受双重领导的机关行文应写明主送与抄送
- 标题格式：**发文机关 + 事由 + 文种**（如《XX局关于XX工作的通知》）
- 成文日期用阿拉伯数字，署会议通过或签发日期；**印章与署名一致**

## 4. 法律高频（背要点即可）
- **宪法**：国家根本法，效力最高；修改需全国人大**全体代表 2/3 以上**多数通过
- **民法典**：民事主体、意思表示、合同、侵权责任、继承、**离婚冷静期 30 天**
- **行政处罚法**：警告、罚款、没收、责令停产停业、暂扣或吊销许可证、行政拘留等；**听证程序**适用较大数额罚款等
- **公务员法**：处分种类 **警告、记过、记大过、降级、撤职、开除**；考核分优秀/称职/基本称职/不称职
- **劳动合同法**：试用期上限（3 个月以下不得约定；1–3 年不超过 2 个月；3 年以上不超过 6 个月）；竞业限制不超过 2 年
- **安全生产法**：主要负责人是本单位安全生产第一责任人

# 五、计算机基础高频（只考选择，精简背诵）

- **数制**：二/八/十/十六进制转换；**1KB=1024B，1MB=1024KB，1GB=1024MB**
- **计算机组成**：CPU（运算器+控制器）、内存（RAM 断电丢失）、外存、总线（数据/地址/控制）
- **操作系统**：进程与线程区别；**死锁四个必要条件**（互斥、请求与保持、不可剥夺、循环等待）；页面置换 **FIFO / LRU**
- **计算机网络**：**OSI 七层**（物理-数据链路-网络-传输-会话-表示-应用）；TCP/IP 四层；**TCP 可靠（三次握手、四次挥手）、UDP 快但不保证**；IP 地址分类与子网掩码；**常用端口 21(FTP)、22(SSH)、23(Telnet)、25(SMTP)、53(DNS)、80(HTTP)、443(HTTPS)**
- **数据库**：主键/外键；**三范式**（1NF 原子性、2NF 消除部分依赖、3NF 消除传递依赖）；**事务 ACID**（原子性、一致性、隔离性、持久性）；基础 SQL（SELECT/INSERT/UPDATE/DELETE）
- **数据结构**：栈（后进先出）、队列（先进先出）；排序复杂度：**快排/归并 O(n log n)**、冒泡/插入 **O(n²)**
- **物联网**：三层架构（**感知层 / 网络层 / 应用层**）；常用协议 **MQTT（发布订阅，轻量）、CoAP**；通信技术 RFID / NB-IoT / LoRa / ZigBee
- **信息安全**：对称加密（AES/DES）速度快、非对称（RSA）用于密钥交换与签名；哈希（MD5/SHA）不可逆；数字签名保证**完整性+不可否认**

# 六、精选练习（分模块 · 高频题型 · 附答案与解析）

> 说明：以下为按高频考点自编的练习，用于练方法与手感；真题请在**牛客网**搜"云南烟草"、粉笔 APP 里练模块。

## A. 资料分析（4 题）
1. 某年云南某行业产值 1200 亿元，同比增长 20%，则上年产值为多少？
2. 某企业 2025 年营收 500 万元，比 2024 年增加 100 万元，增长率约为？
3. 某地区总产量 800 万吨，其中 A 产品 200 万吨；若 A 产品增速 10%，总量增速 5%，则 A 占比相比上年？
   A. 上升　B. 下降　C. 不变　D. 无法判断
4. 2024 年某公司利润 240 万元，2026 年为 345.6 万元，年均增长率约为？

**答案与解析**
1. 基期 = 1200 ÷ 1.2 = **1000 亿元**
2. 增长率 = 100 ÷ (500−100) = 100 ÷ 400 = **25%**
3. **A**：部分增速（10%）> 整体增速（5%）→ 比重上升
4. 345.6 ÷ 240 = 1.44；(1+r)² = 1.44 → 1+r = 1.2 → **r = 20%**

## B. 判断推理（5 题）
5. "如果明天不下雨，我们就去爬山。"若明天**下雨**了，可以推出：
   A. 我们不去爬山　B. 我们去爬山　C. 无法确定　D. 一定下雨
6. 所有实习生都参加了培训；小李没参加培训。可推出：
   A. 小李是实习生　B. 小李不是实习生　C. 无法确定　D. 有人没参加
7. "只有通过笔试，才能进入面试。" 等价于：
   A. 通过笔试 → 进入面试　B. 进入面试 → 通过笔试　C. 未通过笔试 → 进入面试　D. 无等价
8. 图形推理：一组图形对称轴数量依次为 1、2、3、4，下一个应为？
   A. 4　B. 5　C. 6　D. 0
9. 定义：行政授权指上级机关依法将部分职权授予下级行使。下列**不属于**的是：
   A. 省厅将审批权下放至市局　B. 公司经理将任务分配给员工
   C. 县政府依法委托乡镇政府执法　D. 市局将部分许可权授予区局

**答案与解析**
5. **C**：条件命题只保证"肯前必肯后、否后必否前"，否前（下雨）不能推出确定结论
6. **B**：逆否命题——"没参加培训 → 不是实习生"
7. **B**：只有 A 才 B → B → A，即"进入面试 → 通过笔试"
8. **B**：等差递增，下一个为 5
9. **B**：公司经理不属于"行政机关/依法授权"，是内部管理

# 附录 A：申论 2 套万能框架（专卖局可能考）
